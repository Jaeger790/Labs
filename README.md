## Run

For the workstation script, follow its own README. For Snake, open `PublicLabs/Snake/snake.html` in a browser. Java examples with a `pom.xml` can be opened individually in a Maven-capable IDE.

## Source availability

`Animals` and `FirstLinkedList` include source and Maven build files. `ByeWorldFX`, `ColorfulCircles` and `Login` currently contain compiled output without their original source/build files. Their `target/` files are retained as reference material; they are not reproducible source projects. Recover the originals before presenting them as buildable examples.

The cleanup removes IDE state and rebuildable Java output only where matching source is present. Each experiment stays in its existing folder so links and entry points keep working.
